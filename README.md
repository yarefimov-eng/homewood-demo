# HOMEWOOD — статическая демонстрация

**[Открыть сайт](https://velebit-cro.ru/homewood-demo/) · [Открыть демоадминку](https://velebit-cro.ru/homewood-demo/admin/)**

Сайт размещён на GitHub Pages. Аккаунт уже использует собственный домен `velebit-cro.ru`, который GitHub наследует для проектных страниц. Папка демоверсии — `/homewood-demo/`; настройки других проектов не изменялись. Для работы всех возможностей используйте HTTPS-ссылки выше.

Демонстрация существующего сайта и интерфейса управления ассортиментом для GitHub Pages. Использует исходные фотографии, шрифты, CSS, JavaScript и шесть настоящих товаров HOMEWOOD. PHP-версия хранится отдельно в приватном репозитории `homewood-production` и не изменялась для этой публикации.

## Как показать заказчику

1. Откройте опубликованную главную страницу.
2. Прокрутите вниз и нажмите **«Для разработчиков»**.
3. Нажмите **«Открыть демо-панель»**. Настоящего пароля здесь нет.
4. Измените название, цену, описание, категории, фотографию или порядок; нажмите **«Сохранить изменения»**.
5. Нажмите **«Открыть сайт»** — изменения появятся в этом браузере.
6. Кнопка **«Сбросить демонстрационные изменения»** возвращает все шесть исходных товаров, фотографии, цены и настройки.

Доступны добавление, редактирование, скрытие, публикация, подтверждаемое удаление, сортировка вверх/вниз, выбор первого экрана и сброс. Загрузка фотографии проверяет JPEG/PNG/WebP и уменьшает изображение до 1600 пикселей для хранения в браузере. При замене фотографии прежняя геометрия гравировки сбрасывается; новые изделия используют нейтральный предпросмотр.

## Где сохраняются изменения

**Демонстрационная версия. Изменения сохраняются только в вашем браузере. Полноценная версия сайта использует серверную базу данных.**

Каталог и выбранные фотографии хранятся в IndexedDB на устройстве посетителя. Они сохраняются после обычной перезагрузки и перезапуска браузера, пока браузер не очистит данные сайта. Приватный режим и запрет хранения могут ограничить эту возможность; при недоступном хранилище показывается сообщение об ошибке. Разные браузеры и устройства имеют независимые каталоги. Демонстрационный вход — элемент показа интерфейса, а не защита или серверная авторизация.

В демоверсии нет настоящей серверной SQLite, общих изменений для всех посетителей, смены пароля администратора и серверных резервных копий. Эти функции есть в полноценном комплекте для PHP-хостинга. Форма заявки сохраняет исходный принцип подготовки обращения; письма автоматически не отправляются.

## Включить GitHub Pages через браузер

Если публикация ещё не включена:

1. Откройте этот публичный репозиторий и выберите **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. В **Branch** выберите **main**, рядом — **/(root)**.
4. Нажмите **Save** и дождитесь завершения публикации. Адрес появится на той же странице; нажмите **Visit site**.

Проект подготовлен для пути `/homewood-demo/`: ссылки на `admin/`, изображения, CSS и JS используют относительные пути. Точка входа — `index.html`, демонстрационная панель — `admin/index.html`. Файл `.nojekyll` исключает обработку Jekyll. Сборка, npm и дополнительные приложения не требуются.

Полноценную версию скачивают из приватного `homewood-production`: файл `HOMEWOOD-production.zip` → **Download raw file**, либо **Code → Download ZIP** для всех исходников.
